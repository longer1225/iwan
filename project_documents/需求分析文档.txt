个人社交博客系统-需求分析文档（V1.0）
1. 项目概述
1.1 项目简介
本项目是一款集多媒体博客创作、社交互动、即时聊天、AI智能扩展于一体的综合型个人博客平台。区别于传统单一文字博客，系统支持图文、视频多样化内容发布，搭配精细化内容可见权限、好友社交、实时聊天能力，同时预留Python AI Agent、RAG知识库迭代接口，依托PostgreSQL全能数据库、RabbitMQ消息队列、Redis缓存、Nginx反向代理等主流中间件，打造轻量化、工程化、可扩展性极强的个人全栈项目。
项目采用前后端分离架构：Vue3 前端展示、Java SpringBoot 后端服务、PostgreSQL 为主存储（关系型+文档型+向量扩展），适配Windows开发环境，兼顾实用性、美观性与技术先进性。
1.2 项目定位
以个人内容创作与知识沉淀为核心，以社交互动、即时通讯为辅助，以AI智能能力为未来扩展方向，打造多媒体内容博客+轻社交+可AI迭代的综合个人平台，区别于传统纯文字博客和纯娱乐社交平台（Instagram），侧重结构化内容沉淀与工程化技术落地。
1.3 用户角色
系统共划分三类核心用户角色，权限逐层区分：
•	匿名访客：无需登录，可浏览公开内容、发表匿名评论、查看内容基础数据，无任何创作、社交权限
•	注册用户：核心使用角色，支持内容创作、多媒体发布、权限设置、好友管理、即时聊天、内容互动、订阅收藏等全量用户功能
•	系统管理员：平台运维角色，负责用户管理、内容审核、评论管控、系统基础配置，维护平台合规稳定运行
2. 运行与开发环境
2.1 开发系统
Windows 10 / Windows 11 64位（全程兼容，无架构冲突）
2.2 核心技术栈
•	前端：Vue3 + Vite + Element Plus + WebSocket + Axios
•	后端：Java SpringBoot 3.x + Spring Security + JWT + MyBatis-Plus
•	数据库：PostgreSQL 17（支持关系存储、JSONB文档存储、后续pgvector向量存储）
•	中间件：Redis（缓存、在线状态、限流）、RabbitMQ（消息异步分发、聊天解耦、邮件通知）、Nginx（反向代理、静态资源代理）
•	AI模块：Python（预留Agent、RAG知识库迭代能力）
•	部署方式：Docker + Docker Compose（统一环境，便捷部署）
3. 功能性需求
本系统功能分为六大核心模块，所有功能均纳入V1.0版本开发范围，包含基础核心功能与原可选锦上添花功能，无删减。
3.1 用户账号中心模块
3.1.1 基础账号功能
•	用户注册、账号密码登录、退出登录，基于JWT实现无状态鉴权
•	个人信息编辑：支持头像、昵称、个性签名、个人简介修改
•	密码修改、密码找回功能
3.1.2 社交好友功能
•	好友申请：发送申请、接收申请、同意/拒绝好友请求
•	好友管理：查看好友列表、删除好友、自定义好友分组
•	在线状态展示：基于Redis实时缓存用户在线/离线状态
3.1.3 即时聊天功能
•	一对一实时聊天，基于WebSocket实现实时通信
•	RabbitMQ实现聊天消息异步转发、解耦，保障消息可靠投递
•	聊天记录持久化存储（PostgreSQL JSONB），支持历史记录查询
3.2 多媒体内容创作模块（核心）
3.2.1 多样化内容发布
•	支持Markdown/富文本双模式编辑，适配长文博客创作
•	支持图片、短视频多媒体素材上传、预览、插入内容
•	内容属性配置：标题、封面图、摘要、分类、标签
•	内容状态管理：草稿保存、正式发布、在线编辑、永久删除
•	个人素材库：统一管理用户上传的图片、视频素材
3.2.2 精细化可见范围设置（核心特色）
单篇内容独立配置访问权限，后端自动拦截无权限访问请求，支持四种权限模式：
•	公开可见：所有匿名访客、注册用户均可浏览
•	仅好友可见：仅已互加好友的用户可查看
•	仅自己可见：私密内容，仅创作者本人可查看
•	指定分组可见：仅用户自定义好友分组内成员可查看
3.2.3 内容展示与检索
•	首页内容流：按时间排序展示公开多媒体内容
•	分类聚合：按自定义内容分类筛选对应文章/动态
•	标签聚合：通过标签关联、筛选同类内容
•	时间归档：按年、按月聚合展示历史发布内容
•	全局搜索：支持关键词检索标题、正文、标签内容
3.3 内容互动模块
•	点赞收藏：注册用户可对内容点赞、取消点赞、收藏、取消收藏
•	评论回复：支持多级嵌套回复，注册用户可评论、删除自己的评论
•	匿名评论：匿名访客无需登录，可发表匿名评论，统一展示匿名标识
•	内容分享：生成专属分享链接，支持分享至主流社交平台
•	数据统计：单篇内容记录阅读量、点赞数、评论数、收藏数
3.4 个性化与订阅通知模块
•	主题切换：支持浅色/暗黑模式一键切换，配置本地持久化保存
•	账号订阅：用户可订阅其他创作者账号
•	邮件通知：作者发布新内容后，通过RabbitMQ异步推送邮件，通知所有订阅用户
3.5 AI扩展预留模块
•	前端预留AI功能入口：AI辅助写作、内容润色、智能摘要、知识库问答
•	后端预留RabbitMQ/HTTP通信通道，支持对接Python Agent
•	数据库预留向量存储扩展能力，后续可快速接入pgvector实现RAG知识库
3.6 管理员后台模块
•	用户管理：查看全站用户列表、管理用户状态、违规账号处置
•	内容审核：审核用户发布的图文、视频内容，下架违规内容
•	评论管理：查看全站评论、删除违规评论
•	系统配置：基础参数设置、数据统计查看
4. 非功能性需求
4.1 兼容性需求
•	开发环境完全兼容Windows 10/11 64位系统，无适配冲突
•	前端支持主流浏览器适配，页面响应式展示
4.2 性能需求
•	依托Redis缓存热点数据（在线状态、热门内容），提升访问速度
•	RabbitMQ异步处理邮件通知、消息推送，避免主线程阻塞
•	Nginx代理静态资源，优化图片、视频访问性能
4.3 安全性需求
•	基于Spring Security + JWT实现接口鉴权、权限拦截
•	用户密码加密存储，禁止明文传输、存储
•	前后端双重校验文件上传，拦截恶意文件
•	内容权限精准拦截，用户仅可查看授权范围内内容
4.4 可扩展性需求
•	前后端分离架构，业务解耦，便于后续功能迭代
•	PostgreSQL支持向量扩展，无缝对接RAG、AI智能问答功能
•	消息队列预留扩展能力，可新增更多异步业务场景
5. 核心业务流程
5.1 内容发布流程
用户登录 → 进入创作页面 → 编辑图文/视频多媒体内容 → 配置内容分类、标签、可见范围权限 → 保存草稿/直接发布 → RabbitMQ异步推送订阅邮件通知 → 内容持久化入库并对外展示
5.2 内容浏览互动流程
匿名/登录用户访问平台 → 后端根据用户身份自动过滤无权限内容 → 浏览公开/授权内容 → 执行点赞、收藏、匿名评论、分享等互动操作 → 互动数据实时更新入库
5.3 好友聊天流程
用户发送好友申请 → 对方同意成为好友 → Redis更新双方在线状态 → WebSocket建立实时连接 → 聊天消息通过RabbitMQ异步转发 → 消息持久化存储至PostgreSQL → 双方实时接收消息、查询历史记录
6. 功能开发优先级
6.1 P0 核心必做（优先开发）
账号注册登录、个人中心、多媒体内容发布、内容可见权限控制、基础内容展示、匿名评论、点赞收藏
6.2 P1 次核心（迭代开发）
好友管理、一对一即时聊天、暗黑模式切换、内容分享功能
6.3 P2 收尾功能（最后开发）
用户订阅、邮件通知、全站搜索、时间归档、管理员后台完整功能、AI模块入口预留
7. 平台差异化说明（对比Instagram）
Instagram 属于短视频/图片优先的娱乐社交平台，核心为短内容、算法推荐、娱乐社交，不适合长篇知识沉淀；而本项目是以结构化内容创作、知识沉淀为核心，社交聊天为辅助的工程化博客平台，支持长文+多媒体内容，具备权限管控、知识库AI扩展能力，偏向技术落地与个人知识管理，二者定位完全区分。
