2. 整体架构设计
2.1 架构模式
采用业界标准前后端分离、分层架构、事件驱动混合模式：
•	主体业务：分层架构（表现层、业务层、数据访问层）
•	异步业务：事件驱动（RabbitMQ 消息队列解耦）
•	实时业务：WebSocket 长连接（即时聊天）
•	智能业务：预留 Python Agent 微服务接入（后续 RAG 向量知识库）
2.2 技术架构总览
用户访问链路：用户 → Nginx → Vue 前端 → Java SpringBoot 后端 ↔ 中间件集群 ↔ PostgreSQL 数据库
异步智能链路：Java 后端 ↔ RabbitMQ ↔ Python AI Agent（后续 RAG、内容智能处理）
2.3 分层详细设计
2.3.1 前端表现层
技术栈：Vue3 + Vite + Element Plus + Axios + WebSocket
职责：页面渲染、用户交互、表单校验、实时消息监听、主题切换、权限视图控制、多媒体上传、分享功能展示。
2.3.2 网关/代理层
技术：Nginx
职责：静态资源代理（图片、视频）、请求反向代理、跨域辅助、路由分发、开发环境请求统一入口。
2.3.3 后端服务层（核心业务）
技术：SpringBoot3 + SpringSecurity + JWT + MyBatis-Plus
包含三层：
•	Controller 控制层：接收前端请求、参数校验、接口路由分发
•	Service 业务层：核心业务逻辑、权限校验、事务控制、异步调用
•	DAO 数据层：数据库交互、数据持久化、查询封装
2.3.4 中间件支撑层
•	Redis：用户在线状态缓存、热点内容缓存、限流、临时数据存储
•	RabbitMQ：聊天消息异步转发、订阅邮件异步推送、业务解耦、后续AI任务队列
2.3.5 数据存储层
技术：PostgreSQL 17（JSONB + 未来 pgvector 向量扩展）
职责：结构化业务数据、聊天记录、多媒体元数据、扩展字段存储，后续支持 RAG 知识库向量检索。
2.3.6 AI 扩展层（预留）
技术：Python Agent
通过 HTTP / RabbitMQ 与 Java 主服务通信，实现内容智能处理、RAG 问答、文章辅助创作等能力。

3.5 内容互动模块

3.6 订阅与通知模块

4. 核心中间件流程设计
4.1 RabbitMQ 核心业务场景
•	聊天消息：WebSocket 接收消息 → 投递 MQ → 消费者转发接收方 + 入库持久化
•	邮件通知：新文章发布 → 投递 MQ → 异步批量发送订阅邮件，不阻塞发布流程
•	预留 AI 任务队列：文章向量化、AI 摘要生成、RAG 检索任务
4.2 Redis 核心业务场景
•	用户在线状态缓存、心跳检测
•	首页热门内容缓存，减轻数据库压力
•	接口防刷、简易限流
4.3 Nginx 核心业务场景
•	静态资源（图片、视频、静态页面）代理访问
•	统一请求入口，分发前后端请求
5. 全局工程统一规范（强制开发标准）
5.1 统一返回结果规范
所有后端接口统一返回结构体：code（状态码）、msg（提示信息）、data（业务数据）
5.2 统一异常处理
后端全局异常拦截器，统一捕获业务异常、系统异常，避免前端报错裸漏，返回标准化错误信息。
5.3 权限拦截规范
•	未登录用户：仅可访问公开内容、匿名评论、静态页面
•	普通登录用户：可访问自身权限内内容、社交、聊天、创作功能
•	管理员：拥有全平台管理权限
•	内容权限后端强制拦截，前端仅做视图隐藏，防止越权访问
5.4 多媒体文件规范
•	支持图片、短视频上传，前后端双重校验格式、大小
•	文件物理存储服务器本地，数据库存储访问 URL 与元数据
•	Nginx 统一代理资源访问路径
5.5 数据库使用规范
•	结构化业务数据：使用 PostgreSQL 常规字段存储
•	半结构化、灵活扩展数据（聊天记录、扩展配置）：使用 JSONB 高性能存储
•	未来 AI 向量数据：启用 pgvector 插件统一存储
6. 安全与性能概要设计
6.1 安全设计
•	JWT 无状态鉴权，令牌过期自动失效
•	密码加密存储，杜绝明文
•	接口权限、内容权限双层拦截
•	文件上传安全校验，防止恶意文件注入
6.2 性能设计
•	热点数据 Redis 缓存，减少数据库查询压力
•	耗时操作（邮件、消息推送）MQ 异步化
•	静态资源 Nginx 加速访问
•	数据库关键字段建立索引，提升检索效率
7. 扩展性设计（适配未来 AI/RAG）
•	架构完全解耦，AI 模块独立于主业务，不侵入原有博客、社交逻辑
•	PostgreSQL 预留向量存储能力，无需更换数据库即可搭建 RAG 知识库
•	RabbitMQ 预留 AI 任务队列，支持后续批量内容向量化、智能问答任务
•	前端预留 AI 功能入口，后续迭代无需重构页面架构
